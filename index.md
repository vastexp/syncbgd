# syncbgd

**A Personal Google Drive Backup Application for Linux**

syncbgd is a free, open-source application for Linux designed to help users back up their personal files to Google Drive.

The application is developed for personal, non-commercial use and provides a simple way to maintain backups of local files using Google Drive.

## Features

- Back up local files to Google Drive.
- Use Google OAuth 2.0 for secure account authorization.
- Communicate with Google Drive through the official Google Drive API.
- Run on Linux systems.
- Open-source and free for personal, non-commercial use.

## Privacy

syncbgd accesses Google Drive only with the permissions explicitly granted by the user.

The application does not sell personal information, display advertisements, or collect data for commercial purposes.
